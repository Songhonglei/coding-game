V2 布局 review 与重设计 / 2026-11-08

用户问题：代码下方经常出现大块空白，两轮视觉微调仍未解决。
复现：线上0277884，1440x1000，左栏326px，右栏616px；左栏结束到提示区314px空白。
原因：提示区和反思题在双栏 grid 之后，按较高的右栏排版；代码和下一学习动作被分隔。
设计问题：记分牌的画布尺寸跟随列宽无限增长；输出重复展示；新标题字体并不能修复学习路径。

设计方案：一张紧凑实验桌，代码和下一动作在左侧连续，右侧是代码驱动的仪表。
[ 课题 / 变量与赋值 / 三个真实学习步骤 ]
[ 题目 + 三行代码                 | 紧凑记分牌             ]
[ 预测 / 运行 + 当前反馈           | print 输出             ]
[ 达到目标后：解释题              | 执行轨迹（按需展开）   ]
[ 提示 / 词义（按需展开）         |                         ]
两栏独立自然高度，不用最小高度或填充文案拉齐。解释题与反馈的距离不随右栏变化。
手机：题目、代码、操作、结果、解释题、辅助说明，按顺序连续排列；取消悬浮运行栏与相关底部占位。

Token：纸蓝#f4f7fc，白#fff，墨蓝#26334e，群青#314fa6，浅蓝#edf2fc，铅笔黄#f5d86f。
字体：文楷仅用于课题和回顾；系统中文无衬线用于任务正文；系统等宽用于代码。
标题桌面36/手机30，正文14，代码桌面17/手机15–16；正文与代码左对齐。
唯一主要图形是与变量同步的记分牌。收紧场地背景，保留数码管，不增加无功能装饰。

方案自审：
- 放弃把提示移到整行底部以求齐整的做法，它破坏了左侧学习流。
- 不靠卡片填补空白，保留一张实验桌，内部靠分区而非重复圆角卡片建立层级。
- 初始、预测错误、改数、单步、目标未达成、目标达成、回顾、目录均单独验收。
- 检查下一动作与代码的实际距离，并截图审查；横向不溢出只是基础条件。

第二次自审与最终结构：
第一版把后续动作移回左栏后，成功态左栏变长，右侧仪表下方出现新的空洞。未采用该草稿。
最终改为两行结构：上方仅代码与紧凑记分牌并排；下方操作、轨迹与解释题为共用的连续学习区。
记分牌桌面固定180px高（SVG自适应缩放），轨迹移出横向比较区；横向比较区高度不受轨迹、解释题影响。
手机扁平化两层布局容器，阅读顺序为代码、操作、反馈、记分牌、轨迹、解释题、帮助。
验收时同时检查代码→操作的距离、展开轨迹对操作位置的影响、成功解释题的位置。

最终验证：
- tests/v2-layout.browser.mjs 覆盖7个宽度（320/390/760/768/1024/1440/1920）×8个状态。
- 56组均无横向溢出、代码裁切；代码到操作最大桌面41px、手机12px。
- 展开执行轨迹，运行栏位置变化0px；解释题与上方轨迹间距不超过17px。
- 真实浏览器验证错误预测、空输入、单步、错误解释、完成、目录往返、增量0。
- 原版13项回归通过；原版与v3不作改动。
- 截图保存在outputs/v2-rework/，不上传生产站点。
