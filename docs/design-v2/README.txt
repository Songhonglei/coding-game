编程小达人 2.0 / 第二轮交互设计稿

打开 index.html 即可体验，不需要安装依赖或启动后端。
本稿保留在 codex/v2-design 分支；生产版本仍为 main 上的 1.0.1。

这一轮的主要变化：
- 使用“校园比赛记分牌”这一具体课堂题材，让每个图形对应代码里的分数。
- 采用明亮实验册版式，减少圆角面板、装饰插画、胶囊标签和宣传口号。
- 代码与实验场景并排，执行行、变量记录和输出相互对应。
- 学生先预测，再修改，最后解释；有基础的学生可直接动手。
- 手机端提供跳到记分牌的结果链接，避免运行后找不到反馈。

体验路线：
1. 预测三行代码的输出。正确是 8；答错会有针对性提示。
2. 把第二行的数字改成 3，运行或单步观察，得到 10。
3. 在“解释你的发现”中选择“存回 score”，完成这课并查看实验记录。
4. 可以回实验尝试 0，或打开课程目录。

已检查：
- 预测错误提示、正确预测和跳过引导。
- 单步与直接运行结果一致；增量3得到10，增量0得到7。
- 空输入显示修正提示。
- 解释错误时可重选，解释正确后进入回顾。
- 课程目录往返与重做。
- 390px 视口无横向溢出；1440px 桌面布局和截图。

范围：这是第二轮设计提案，不是 2.0 完整产品。
只支持本课三行示例的受限模型，不执行任意 Python。
没有账号、云同步或全课程；目录中的后续课程明确标为规划。
尚未做真实学生试用、实体手机或完整无障碍验收。
