编程小达人 2.0 / 第二轮设计 / 2026-11-07

定位：四年级到初三的编程入门实验课。保留“短任务、读代码、修改、观察”的学习结构。

第一稿的问题：
1. 绿色、圆角面板、吉祥物和扁平森林插画组合过于通用，缺少与这门课有关的独特内容。
2. “用代码改变世界”等口号占据空间，不能帮助学生完成当前任务。
3. 图像像背景海报，学生尚不能理解每个图形与变量的关系。

第二轮方向：一本可以运行的编程实验册。
场景选用校园比赛记分牌：变量保存分数、赋值更新分数、print显示分数，动作和结果具有直接关系。
第一课交互：先预测 7+1 的输出，再修改增量使记分牌显示10，最后补全一句话解释赋值。

设计 Token：
纸面 #F7F8FB；白 #FFFFFF；墨蓝 #24304C；群青 #314FA6；浅蓝 #E9EEFC；铅笔黄 #F5D86F。
中文 PingFang SC / Microsoft YaHei，标题30–36、正文15–16、注释12–13。
代码 SFMono-Regular / Consolas，16–18，使用明亮纸面，与正文共享阅读节奏。
不使用渐变、漂浮粒子、励志口号、进度经济、全屏漫画或各处独立圆角卡片。

宽屏对齐代码、实验场景的顶部；左对齐正文。窄屏按题目、代码、操作、结果顺序阅读。

记忆点只用在记分牌：完整七段数字、场地标线和变量对应关系，不叠加角色与装饰。
输入、单步、输出和解释全走同一个变量模型；显示当前执行行。
默认有引导；读码预测可反复尝试，不把尝试次数包装成排名。
支持键盘、减少动态、窄屏；只有结果更新时使用一次短过渡。

自审：草图最初沿用三列工作台；已改成双页实验册，避免后台仪表盘感。
课程目录使用真实顺序列表，不用锁住的卡片铺满屏幕。
保留品牌原名，不把新风格强加成一次品牌改名。

范围：第二轮交互设计稿；与 1.0.1 分支隔离，不部署到生产。
不是通用 Python 执行器。只执行示例三行代码的受限模型，后续课程明确为规划。
